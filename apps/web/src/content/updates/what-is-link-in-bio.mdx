## A link in bio is a profile link people are asked to open

When a post says “link in bio,” it means the creator has placed a web address on their social profile and wants visitors to open that profile link for more information. The phrase is common on platforms where a post caption is not the main place to present several destinations.

The destination might be one article, a new release, a shop, a portfolio, or a page that organizes several links. The phrase describes where to look; it does not mean every profile needs a separate link tool.

## One direct link or a page with several choices?

If you are promoting one current item, linking directly to it can be the shortest path. If you regularly share different projects or use several social profiles, a page can provide one stable address and a clear set of choices. Instagram also lets people add multiple links directly to a profile; [Meta announced that change](https://about.fb.com/ko/news/2023/04/instagram%EC%9D%B4-%EC%9E%90%EC%9C%A0%EB%A1%9C%EC%9A%B4-%EC%9E%90%EA%B8%B0%ED%91%9C%ED%98%84%EC%9D%84-%EC%84%A0%EB%B3%B4/).

Use a separate page when the extra context or presentation helps visitors choose. A photographer might show a featured image before linking to a gallery. A writer might place a current article next to a newsletter link. If the extra page adds no useful context, keep the route direct.

## Make the destination match the promise

If a post says “new collection,” put that collection near the top of the destination. If a bio says “freelance illustrator,” show relevant work before unrelated social links. Use labels that describe the destination rather than vague buttons such as “click here.”

Grabbin can arrange text, images, videos, places, and links on one visual page. It points visitors to your existing destinations; it does not replace a store, booking system, or long-form portfolio. For layout ideas, see [how to build a visual link-in-bio page](/update/build-visual-link-in-bio) and [examples of portfolio pages](/update/portfolio-website-examples).

## Check the whole path

Open the profile as a visitor, tap the link, and then tap the next destination. Remove outdated choices and make the current one easy to spot. A “link in bio” callout only helps when the profile address works and the page delivers what the post promised.
