## Make the first set of images current and clear

A model portfolio website should make it easy to review a current selection of images. Choose photos that show the range relevant to your work rather than repeating one look in several similar frames. Keep the first selection focused, then link to a fuller portfolio if you maintain one.

Confirm image credits and usage rights before publishing. If a photographer, agency, or client should be credited, add that context where appropriate. Do not present an old campaign image as current work if that would mislead a visitor.

## Label the next step carefully

If you are represented, link to the current agency profile or contact page and use a label that says what it opens. If you manage inquiries yourself, link to the email address or form you already use. Avoid publishing private information that you do not want indexed or copied.

If you include measurements or location, keep them accurate and share only what is necessary for your professional page. Review the page whenever those details change.

## Decide whether you need a full portfolio site

A compact visual page can put a headshot, a few images, and professional links together. A full portfolio site may be more suitable when you need multiple galleries, detailed categories, or larger image files. Use a page builder as an introduction only when it fits the depth of your work.
