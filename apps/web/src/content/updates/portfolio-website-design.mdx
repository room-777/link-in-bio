## Let the project determine the visual order

Portfolio website design is not only about choosing a color palette. The arrangement should help a visitor understand which work to look at, what they are seeing, and where to go next. Give your strongest relevant project more attention than a secondary social profile.

## Use media with a short explanation

Choose an image or video that shows the work clearly at the size it will appear. Add a caption or note when the media needs context: what the project is, what you contributed, or where the full case study lives. Do not put unsupported client results in the caption.

The project note can stay brief. A phrase such as “Editorial illustration series, created for an independent magazine” gives more context than a title alone, as long as it accurately describes the work.

## Design desktop and mobile as separate reading checks

On a wide screen, side-by-side blocks can connect an image with its description. On a phone, the same blocks may stack. Check that the sequence still makes sense: introduction, featured work, supporting work, then contact or related links. Reorder content if important work falls too far down the page.

## Use a small system for consistency

Keep project titles and link labels consistent. Reuse a short caption structure and similar image crops where it helps visitors compare work. Leave enough space between sections so a new project reads as a new item rather than a continuation of the previous one.
