## Let one photograph introduce the kind of work you do

A photographer's link-in-bio page can help a visitor understand your work before opening a full gallery. Choose a strong image that represents the work you want to show now. Add a short note naming the specialty or subject so the image has context.

Do not make a visitor guess which gallery is relevant. Use labels such as “Portrait portfolio,” “Recent weddings,” or “Editorial work” only when those destinations exist and match the words.

## Build a small set of useful destinations

Start with the galleries or case studies you want people to view, then add a contact route and any active information that matters, such as a current exhibit or a location. If you link to booking software, make clear that the visitor is leaving the page to contact or reserve through that service.

Use only images you are allowed to share. Check client permissions, model releases, and credits before publishing. If a full-resolution portfolio lives elsewhere, link to it rather than compressing every image into the bio page.

## Make the page work for mobile visitors

Open the page on a phone and check that the first image is not cropped in a way that changes the subject. Place the most important gallery before general social links. Tap every destination and confirm it loads quickly enough to view.

Grabbin can arrange photos, videos, short text, places, and links together on a visual page. It points to an existing portfolio or booking service; it does not host a booking form or manage sessions.
