## Instagram gives you a direct choice and a page choice

You can place links on your Instagram profile, and Meta announced support for up to five profile links in 2023. That makes a separate bio page optional for many people. The right choice depends on whether visitors need only a few destinations or a more complete introduction to your work.

Use Instagram's native links when each destination is clear and the list is short. Choose a separate page when you want to combine links with selected media, short explanations, or a more deliberate visual order. The page should add value beyond repeating the same links in a different place.

## Set up the path around one audience

Imagine a visitor arriving after watching a short video. They may want the full project, your other work, or a way to contact you. Put those options in that order. Avoid adding every platform account if it makes the main action harder to find.

For a visual creator, a useful first screen might include:

1. A name and short description of the work.
2. One featured photo, video, or current project.
3. A clearly labeled link to the full collection.
4. A small set of additional destinations.
5. A contact route, if you want inquiries.

If a visitor needs to book or buy, link to the service that handles it. Grabbin can organize those destinations alongside media and text, but it does not provide booking or checkout itself.

## Add and test your link

In Instagram, open your profile settings and look for the profile editing area for links. Labels can change, so follow the current in-app controls. Paste the full public page address, save the change, then reopen your profile as a visitor. Check both the profile destination and every link on that page.

Keep a direct link when it is the shortest route. If a page helps visitors understand who you are before choosing, compare the [link-in-bio tool checklist](/update/choose-link-in-bio-tool) and the [Instagram bio writing guide](/update/write-instagram-bio).
