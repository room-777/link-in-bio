## Explain your practice in ordinary words

An artist portfolio website does not need a long statement before visitors can view the work. Start with a sentence about your medium, subject, or current focus. A visitor should know whether they are looking at painting, illustration, ceramics, photography, or another practice without having to infer it from the image alone.

## Choose work that belongs together

Select a few pieces from a series or a group that shows your current direction. For each one, include a title and the details that matter to the viewer. If the collection is large, link to the full archive rather than shrinking every work into one crowded page.

Use only images that you have permission to publish. Make sure the crop does not remove an important part of the work, and test the larger destination if visitors need to zoom in.

## Add links that support the next conversation

You might link to a complete portfolio, a gallery profile, an exhibition page, a shop, or a contact method. Name each link by what it opens. If you take commissions, link to the inquiry route you already use; do not imply that a bio page accepts or manages requests by itself.

Grabbin can place work images beside short notes and links on one page. It is a visual introduction, not a replacement for an archive or commerce platform.
