## Select a collection instead of showing every piece at once

An art portfolio website should make a small group of works easy to explore. Start with a series, medium, or current body of work. A focused selection gives visitors a reason to open the full collection without forcing them to scan everything you have made.

For each piece, include the title and any details that help someone understand it, such as medium, year, dimensions, or series. Add only information that is accurate and that you want public. If a gallery or client owns the image rights, confirm that you may display it.

## Make the image and its destination work together

Use an image that remains legible in the page layout. If the work needs a larger view, link to a page where someone can see it at full size. Label the link clearly; do not make every image open the same generic homepage.

## Keep the rest of the artist page useful

Add a concise introduction, a link to the full portfolio, and a contact route if you welcome inquiries. If you sell work, link to the shop that manages its availability and payment. A profile page can introduce a collection but should not imply that it handles inventory or checkout when it does not.
