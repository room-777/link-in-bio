# UI 작업 스킬

사용자가 요청한 작업의 성격에 맞는 아래 전역 스킬을 작업 전에 반드시 사용한다. 여러 범위가 겹치면 해당 스킬을 모두 사용하고, 각 스킬의 `SKILL.md`를 먼저 읽는다.

- UI 개선, 컴포넌트, 시각적 완성도, 표면 깊이, 아이콘, 히트 영역: `better-ui`
- 색상 시스템, OKLCH 변환, 색상 변환, 팔레트, 대비 확인, 색상 범위 보정: `better-colors`
- 접근성 표준, 포커스 상태, 키보드 이동, ARIA, 폼, 스크린 리더, 히트 영역: `better-accessibility`
- 그룹화, 정렬, 읽는 순서, 점진적 공개, 반응형 레이아웃: `better-layout`
- 접근성, 레이아웃, 문구, 타이포그래피, 색상, UI 다듬기를 한 번에 검토: `better-interface`
- UI, 타이포그래피, 레이아웃, 색상, 문구, 접근성 등 여러 범주에서 작업 결과를 검토하고 발견 사항을 자세히 분석: `interface-review`
- UI 구성, 디자인 세부 사항, 호버·포커스·활성·로딩 상태, 모션과 마이크로 인터랙션을 다듬을 때: `make-interfaces-feel-better`
